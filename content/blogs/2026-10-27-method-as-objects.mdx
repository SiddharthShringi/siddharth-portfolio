In ruby, methods are not object by default but there is way
we can change method into an object.

But the first question comes is:

# Why would we want to convert method into an object?

So that we can store them in variable and pass around.
Let's understand this:

But what problem are we solving by storing an method into a variable?

Let's say we have below methods:

```ruby
def greet
  puts "Hello there!"
end

def say_bye
  puts "Good Bye!"
end
```

We can say that a method is a name given to peice of behaviour.
When we call these methods Ruby executes the behaviour.

These methods already have a name,
so whenever we want to use them we can call them.

**Why do we need to store them in variable then?**

Let's suppose, we are building a notification system, where we have send notification based on a certain time. Somtime we would like to greet a user and sometime we would send goodbye notification.

So how are we going to implement this with our current knowledge. Using `IF/ELSE` conditions or `switch/case`

```ruby
def send_notification(user_action)
  if user_action == :greet
    greet
  elsif user_action == :leave
    say_bye
  end
```

But as the type of notification increses, the number of condition will also increase and make this method bulky.

But what if there would have been a way where we can just pass the behaviour we want to execute and later when we want we could execute it.

Let's try with current setup. Let's try to store method into a variable.

```ruby
notification = greet
```

What Ruby does is, it executes the `greet` method immidiately and save the result in the variable not the behaviour of method.

It reveals two things here:

1. Calling a method means executing a behaviour.
2. Holding a reference to a method means being able to refer that method behaviour without executing it yet.

We would like to achieve second thing, to achieve that we would need to convert method into an object so that variable can refer to them.

And later we can pass that method **behaviour** and call it later when we want them to call.

# How do we convert method into an object?

Let's see how we can do it.

```ruby
def greet
  puts "Hello!"
end

say_hello = method(:greet)
```

Here `method(:greet)` gives us `Method` object that refers to behaviour of `greet` method. `say_hello` variable holds that method object.

Now when we want to call it, we can do it like this:

```ruby
say_hello.call
```

Let's do it with our `send_notificaion` method

```ruby
def send_notification(user_action)
  user_action.call
end

send_notification(method(:greet))
send_notification(method(:say_bye))
```

We achieved our objective and
